# kanteen
Kanteen is a web application built using React.js that aims to streamline the billing process of a canteen in an institution. It provides a user-friendly interface for managing orders, tracking cash flows, and generating useful analytics for the admin to make informed decisions about menu curation and management.

# Key Features:

<ul>
  <li>Order Management: Users can easily place orders for food and beverages through the intuitive interface.</li>
  <li>Billing System: Efficiently manage billing and payments for orders, including options for cash, card, or digital payments.</li>
  <li>Analytics Dashboard: Provides detailed analytics and insights to the admin, such as popular items, sales trends, and revenue reports, to optimize menu offerings and pricing.</li>
  <li>User Authentication: Secure user authentication and authorization system to ensure data privacy and access control.</li>
  <li>  Responsive Design: Designed with a responsive layout to ensure compatibility and usability across various devices and screen sizes.</li>
</ul>

# Technologies Used:

<ul>
  <li>Frontend: React.js, HTML, CSS, JavaScript</li>
  <li>Backend:  Node.js, Express, MongoDB</li>
  <li>Libraries & Tools: Redux, Bootstrap, Axios</li>
</ul>
